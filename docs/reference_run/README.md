# Reference run

Metric and analysis artifacts from the verification build on the official OULAD data (2026-10-10, scikit-learn
HistGradientBoosting engine because XGBoost was unavailable in the build sandbox; LLM not connected, so AI-feature
sections show computed paths only). Checkpoint-specific files are for the default checkpoint (week ~15).
`docs/MODEL_CARD.md` and the deck were generated from these files. `make build` writes fresh artifacts and `make report`
regenerates the documents.
